# USENIX Security 2027 Artifact

This repository will contain the code and experimental materials for a submission to the 36th USENIX Security Symposium (USENIX Security 2027).

## Repository Structure

The artifact directories correspond to the paper as follows:

- `Code/Attack_t0` contains the implementation and experiments for Chapter 4.
- `Code/Attack_s1` contains the implementation and experiments for Chapter 5.
- `Code/one_bit_attack` contains the implementation and experiments for Chapter 6.
- `Code/rej_2026_D2_SCA` contains the side-channel experiments presented in Chapter 7.
- `Code/dilithium_forgery` contains the signature-forgery experiment presented in Chapter 7.
